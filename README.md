## 📖 معرفی CutterLog

**کاترلاگ (CutterLog)** دستیار جامع، مدرن و کاملاً آفلاین برای تدوین‌گران و تدوین‌خانه‌هاست. در فرآیند حرفه‌ای تدوین، مدیریت همزمان چندین استودیو طرف حساب، پروژه‌های موازی با صدها کلیپ مجزا، دورهای متعدد بازبینی و اصلاحات (Revisions)، ثبت تایمر دقیق کارکرد برای محاسبه دستمزد ساعتی، صدور فاکتور و پیگیری تسویه‌حساب‌ها همیشه یکی از چالش‌های زمان‌بر است.

کاترلاگ این فرآیند را در یک بستر بصری سینمایی، دارک و مطابق استانداردهای طراحی **Material Design 3** با تایپوگرافی اصیل فارسی گرد هم آورده است.

## ✨ قابلیت‌های کلیدی

### ۱. 🗂️ میز کار و مدیریت پیشرفته پروژه‌ها (Workspace)
- **داشبورد وضعیت تدوین**: دسته‌بندی پروژه‌ها بر اساس وضعیت واقعی:
  - `در حال راف کات (Rough Cut)`
  - `مرحله فاین کات (Fine Cut)`
  - `اصلاح رنگ و نور (Color Grading / DI)`
  - `صداگذاری و میکس (Sound Design)`
  - `تحویل نهایی (Final Delivery)`
  - `مختومه در آرشیو`
- **تفکیک کلیپ‌ها و بخش‌های پروژه**: ثبت تایتل‌ها، تیزر، کلیپ رقص، فرمالیته، بله‌برون، مراسم اصلی و قطعات اختصاصی با امکان تیک زدن وضعیت تکمیل هر کلیپ.
- **طرف حساب‌ها و استودیوها**: تعریف استودیو با لوگو، تلفن، آدرس و نرخ‌های توافقی ثابت یا ساعتی.

### ۲. ⏱️ تایمر کارکرد و تایم‌شیت تدوین (Timer & Work Sessions)
- **تایمر اختصاصی شیفت تدوین**: ثبت زمان صرف‌شده روی هر پروژه با دقت میلی‌ثانیه و نمایش تایم‌کد دیجیتال (ساعت، دقیقه، ثانیه).
- **ثبت جلسات کارکرد**: محاسبه خودکار ساعات مفید کاری، یادداشت‌گذاری برای هر شیفت و ثبت لاگ در تاریخچه پروژه.
- **تخمین هزینه ساعتی**: ضرب اتوماتیک زمان کارکرد در نرخ ساعتی تدوینگر برای استعلام و صورتحساب.

### ۳. 📝 ثبت و مدیریت سوابق اصلاحات (Revisions & Review Rounds)
- **پایان ناهماهنگی در اصلاحیه‌ها**: ثبت ساختاریافته راندهای اصلاحی (`Round 1`، `Round 2`، `Round 3` و...).
- **چک‌لیست دقیق آیتم‌ها**: شرح هر اصلاحیه ارسالی از سوی کارگردان یا مشتری، زمان درخواستی، وضعیت اجرا و تاریخ تکمیل.
- **جلوگیری از زیاده‌خواهی و تغییرات بی‌پایان**: ایجاد مستندات شفاف از تمام تغییرات اعمال‌شده در هر مرحله.

### ۴. 💰 حسابداری، فاکتور و امور مالی (Finance & Invoicing)
- **مدیریت درآمدها و مطالبات**: محاسبه اتوماتیک جمع کل قراردادها، مبالغ بیعانه و تسویه‌شده، و مانده مطالبات به تفکیک استودیو.
- **صدور پیش‌فاکتور و فاکتور رسمی**:
  - درج شماره سریال فاکتور و تاریخ هجری شمسی
  - مشخصات کامل مشتری/استودیو و تدوینگر
  - جدول ریز اقلام و پروژه‌ها
  - تبدیل خودکار مبالغ به حروف به تومان و ریال
  - اعمال تخفیف، پیش‌پرداخت و مشخصات شماره شبا / کارت
- **خروجی گرافیکی فاکتور**: ذخیره فاکتور در قالب تصویر باکیفیت بالا (PNG) و آماده برای ارسال در پیام‌رسان‌ها.

### ۵. 📦 آرشیو هوشمند پروژه‌ها و صدور شناسنامه (Project Report)
- **انتقال امن به بایگانی**: آرشیو پروژه‌های تکمیل‌شده با حفظ کلیه اطلاعات، جلسات تایمر، پرداخت‌ها و کلیپ‌ها.
- **پیش‌نمایش رسمی سند گزارش (Project Report Preview)**:
  - طراحی ویژه به سبک سند رسمی مدیریت پروژه با گرید کامپکت و خوانا
  - شاخص‌های کلیدی: تعداد کل کلیپ‌ها، اقلام تحویل‌شده، راندمان زمانی، درصد پیشرفت و تاریخچه اصلاحیه‌ها
  - وضعیت مالی و تاییدیه تسویه‌حساب نهایی
- **اکسپورت دوگانه**:
  - خروجی سند استاندارد **PDF**
  - خروجی پوستر تصویری با رزولوشن بالا **PNG** با مهر دیجیتال

### ۷. ⚙️ بخش تنظیمات مینیمال و شخصی‌سازی (Settings & Preferences)
- **چیدمان منظم و یکپارچه**: هماهنگی دقیق آیکون‌ها و متن‌های بخش تنظیمات (عمومی، مالی، پکیج‌ها، ایمنی، مرکز بازنشانی و درباره کاترلاگ).
- **حمایت از توسعه‌دهنده**: دکمه اختصاصی «یک قهوه مهمان کن» با پالت رنگی گرم و قهوه‌ای.
- **شناسنامه درون‌خطی (Inline About)**: مشاهده اطلاعات نسخه، مشخصات سازنده و جزئیات نرم‌افزار بدون نیاز به پاپ‌آپ و به صورت کاملاً سریع و دسترسی‌آسان.

## 🏗️ معماری و فناوری‌های به‌کاررفته

پروژه براساس استانداردهای روز دنیای اندروید و **Clean Architecture / MVVM** پیاده‌سازی شده است:

```
app/src/main/java/com/example/
├── data/
│   ├── database/
│   │   └── AppDatabase.kt          # دیتابیس Room با پشتیبانی از TypeConverters و Migrations
│   ├── dao/
│   │   └── AppDao.kt               # کوئری‌های واکشی، ثبت، ویرایش و گزارش‌گیری
│   ├── entity/
│   │   ├── Entities.kt             # موجودیت‌های Project, Studio, Clip, Revision, Session
│   │   └── InvoiceModel.kt         # مدل داده فاکتور و ریز محاسبات مالی
│   └── repository/
│       └── CutterLogRepository.kt  # تفکیک لایه داده و بیزینس لاجیک
├── ui/
│   ├── components/                 # کامپوننت‌های ماژولار (دیالوگ‌ها، هدر، نویگیشن، پیش‌نمایش گزارش)
│   ├── screens/                    # صفحات اصلی (Workspace, Timer, Finance, Archive, CutterPilot, Settings)
│   ├── theme/                      # تایپوگرافی، پالت رنگی دارک استودیو، فونت‌های Vazirmatn
│   ├── util/                       # ابزارهای کمکی UI و ترنسفورمیشن مبالغ
│   └── viewmodel/                  # StateFlows و مدیریت چرخه‌حیات داده‌ها
└── util/
    ├── PersianUtils.kt             # تبدیل تاریخ شمسی، اعداد فارسی، حروف‌نویسی مبالغ
    ├── InvoiceExporter.kt          # موتور رندرینگ و اکسپورت فاکتور
    └── ProjectReportExporter.kt    # موتور تولید اسناد PDF و تصاویر گزارش کار
```

| مؤلفه | تکنولوژی مورد استفاده |
| :--- | :--- |
| **Language** | Kotlin 2.0+ (100% Coroutines & Flow) |
| **UI Toolkit** | Jetpack Compose (Material 3 Declarative UI) |
| **Local DB** | Android Room Database (SQLite Engine) |
| **Typography** | Vazirmatn (وزیرمتن) با پشتیبانی کامل از قلم‌های Regular, Medium, Bold |
| **Layout** | Native Right-To-Left (RTL) First |
| **Document Export** | Android Native Canvas, PdfDocument & MediaStore API |
| **Architecture** | Single-Activity MVVM + Repository Pattern |

## 🎨 استانداردهای بصری و طراحی (Design System)

- **Dark Cinematic Theme**: استفاده از طیف‌های مشکی کربنی (`#060910`) و سرمه‌ای تیره (`#0B1120`) با اکسنت بنفش نئونی تدوین (`#7C3AED`) جهت کاهش خستگی چشم تدوینگران در محیط‌های تاریک سوئیت تدوین.
- **RTL بومی و بی‌نقص**: کلیه کامپوننت‌ها با جهت‌گیری راست‌به‌چپ، فواصل متناسب با خط فارسی و بدون شکستگی ناخواسته کلمات پیاده‌سازی شده‌اند.
- **تبدیل هوشمند اعداد**: تبدیل کلیه تایم‌کدها، شناسه‌ها و مقادیر ریالی به ارقام استاندارد فارسی با جداکننده‌های سه‌رقمی.

## 🔒 امنیت داده‌ها و حریم خصوصی
- **۱۰۰٪ محلی و آفلاین (Offline-First)**: تمام اطلاعات مالی، اسامی مشتریان، نرخ‌ها و گزارش‌ها در دیتابیس لوکال دستگاه ذخیره شده و به هیچ سرور خارجی ارسال نمی‌گردد.
- **بدون نیاز به دسترسی‌های خطرناک**: ذخیره‌سازی فایل‌های PDF و PNG از طریق استانداردهای MediaStore و Share Intent انجام می‌پذیرد.
